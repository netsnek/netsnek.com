# セキュリティ

このセクションの背後には、長いあいだ私を捉えて離さなかった2つのプロジェクトがあります。どちらも同じ問いをめぐっています。本当に自分のものであり、しかも何かに耐えられるデジタルアイデンティティを、私はどう作るのか。

[YubiKey PIV Restore](/docs/security/piv) のテーマは、失うことへの恐れです。ハードウェアキーは素晴らしく安全で、まさにそれゆえに後戻りができません。ここでは、私がそこに紙のバックアップを与えた方法と、なぜ最終的にたったひとつの公開鍵が TON ウォレットとして、カードの鍵として、そして PGP のプライマリキーとして働くのかを語ります。

[QES-OIDC](/docs/security/qes-oidc) のテーマはログインです。パスワードを打ち込む代わりに、ID Austria で短いテキストに署名します。すると、その適格署名からごく普通の OpenID Connect ログインができあがります。始まりは、本当に署名した人だけが会員になれる団体の入会手続きでした。

メールサービス [Emailwerk](/docs/emailwerk) では、この2つが出会います。そこではメールが、適格署名が揃うまで待つことができ、YubiKey の鍵がその正確な内容にも同時に署名します。一方の署名は、誰が送るのかを示します。もう一方は、途中で誰も何も変えていないことを示します。
