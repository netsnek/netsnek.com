# LEDアート

このセクションには、私が Andreas と一緒に作った LED アートプロジェクトを集めています。

Andreas は電気とレーザーの技術者で、私はソフトウェアとセキュリティの出身です。彼が何に心を注いでいたのかを見たい人へ。[eiergeier.at](https://eiergeier.at) には2000年代初頭から彼のレーザーと照明技術のページがあり、自作のレーザーヘッドや DMX512 制御が並んでいます。紙の上では、これは切り離された2つの世界です。けれど工房では、それは同じ問題に対する2つの視点でした。そして私はまさにそこから計り知れないほど多くを得ました。技術者は電流と公差と材料で考え、私は状態とプロトコルとエラーケースで考えます。その2つが出会うところに、どちらか一人では思いつかなかったプロジェクトが生まれます。

この協働から私が得た本当の教訓はこれです。隣接する専門分野とのパートナーシップは、ソフトウェア会社にとって付け足しではなく、新しいものが生まれる最良の源のひとつだということ。それは価値をもたらし、そしてたっぷりの楽しさをもたらします。Andreas との LED プロジェクトは、その両方でした。

Andreas は2026年の初めに亡くなりました。これらのページは、彼と、共に重ねた仕事の思い出のためにあります。私たちが一緒に作り上げたものを記録し、これらのプロジェクトに宿る喜びを残しておくためのものです。

個々のプロジェクトの記事は、資料の整理ができ次第掲載します。
