# 私たちが Walthergruppe と一緒に PhotonQ を作った話

ウィーン大学の物理学部では、光で計算が行われています。光量子コンピューティングのためのクリスチャン・ドップラー研究所、すなわち Walthergruppe が、そこで光子を使う量子コンピューターを研究しています。この研究をどうやって実験室からブラウザーへ持ち出すか、という問いから PhotonQ が生まれました。そして PhotonQ は、Netsnek e.U. の歴史の中でもっとも印象深いプロジェクトの1つになりました。ここで私が「私たち」と書くとき、それは文字どおりの意味です。PhotonQ は一度も一人のプロジェクトではありませんでした。当時の私たちは小さなチームで、このプラットフォームには関わった全員の筆跡が残っています。

## PhotonQ とは何か

PhotonQ はこのグループのオンラインプラットフォームです。自らをオーストリア初の光量子コンピューティング・オンラインプラットフォームと称し、その掲げるものはトップページに直接書かれています。make quantum accessible to all。

具体的にはこうです。アカウントを作り、量子回路を OpenQASM で書き、それを回路図として見て、実験として実行します。変換とシミュレーションには Perceval、Qiskit、PyZX が使われます。デモとして、トップページでは quantum ripple-carry adder が計算されます。量子ゲートでできた小さな加算機です。さらに4部構成のドキュメントがあり、量子情報の基礎から線形光学、測定型量子計算、そして OpenQASM までを扱います。

## 私たちが作ったもの

プラットフォームそのものです。photonq.org は、私が今も開発を続けているオープンソース CMS [Jaen](/docs/jaen) を使った Gatsby サイトです。PhotonQ はこれによって Jaen のリファレンスサイトの1つになりました。コードは公開されていて、リポジトリはいまや875コミットに達しています。核となる部分は2023年にでき、遅くとも2024年初頭からプラットフォームは本番稼働していました。

特に気に入っている部分が2つあります。1つ目はプレイグラウンドです。ドキュメントは MDX でできていて、テキストの真ん中に QASM エディターが独立した部品として座っています。ある章を読み、コードを1行変えると、すぐに新しい回路が見えます。2つ目はコミュニティ部分です。実験はプロフィール、スター、フォロー、アクティビティフィード、そして30日間のトレンドランキングを伴う投稿になります。どの実験も最初は非公開の下書きとして始まります。公開されるのは、自分の準備ができてからです。この初期設定は、今でも正しかったと思っています。

その裏側で動いているのはモノリスではありません。フロントエンドは生成された GraphQL クライアントを通じて、私たちが Pylons と呼ぶ小さなサービス群と会話します。当時はまだ snek functions という名前でした。1つはプロフィールと投稿を管理し、1つは登録を担当し、1つは実験の OpenQASM コードを実行します。アイデンティティとログインには専用のアイデンティティプロバイダーを使っています。プラットフォームは、グループと一緒に取り決めた環境で運用されています。

## 協働について

役割分担は最初から明確でした。Walthergruppe が科学を担い、ドキュメントの各章にはその帰属が記されています。トップページには開発パートナーとして Netsnek と cronit studios の名が載っており、共同のインフラ上では今日に至るまで cronit のサービスも動いています。これらの社名の裏には、私たちの側では息の合った小さなチームがいて、まさにこのチームワークがプラットフォームを可能にしました。

ウェブサイトのプロジェクトからは、それ以上のものが生まれました。今では Netsnek がグループのインフラを見ており、私は彼らのアイデンティティアーキテクチャを、今度は型付きの GraphQL API を上に載せる形で新たに構築しています。

このプロジェクトを私にとって支えてくれたのは、とりわけグループの2人でした。[Felix](https://www.linkedin.com/in/felix-zilk/) と [Tobias](https://www.linkedin.com/in/tobias-guggemos-0307358a/) です。PhotonQ を一緒に実現できたことに、私は今もこの2人にとても感謝しています。物理学者とソフトウェアの人間が同じテーブルに着き、最後にブラウザーの中の量子コンピューターができあがる。まさにこういう協働のために、私は Netsnek を創業したのです。

## PhotonQ が私に教えてくれたこと

ソフトウェアは受け継がれます。PhotonQ は私の Jaen テンプレートから生成されました。このテキストが載っているサイト netsnek.com は、今度はその PhotonQ のコードから生まれました。2026年8月のリニューアルでは、プレイグラウンドと実験ページ、そして PhotonQ のテーマ系統をまるごと、エージェンシーのサイトからまた切り離しました。自分のコードには、何年も経ってから新しい文脈で再会するものです。

そして時には、根拠のある「ノー」が最良の判断になります。2026年7月、私は PhotonQ のコミュニティ部分が Bluesky の AT Protocol に載るかどうかを計算してみました。公開部分はほぼ一対一で対応します。非公開の下書き、投稿の取り下げ、閲覧統計、そして GDPR の削除義務は対応しません。だから移植ではなく、せいぜいシンジケーションの橋渡しです。プロトコルがいつの日か非公開データを扱えるようになれば、の話ですが。

## プロジェクトから生まれたドキュメント

PhotonQ の核心には、量子コンピューティングを理解できるものにするという志が常にありました。だからこそ、このプロジェクトから生まれた量子コンピューティングのドキュメントはここで生き続けます。以下のサブページには、量子コンピューティングと量子情報、線形光学、測定型量子計算、そして OpenQASM の各章があります。

そこには警告も添えておきます。いや、むしろ招待でしょうか。これらの章には本当にたくさんの数学が詰まっています。状態ベクトル、行列、測定確率。それは事故ではなく、狙いです。量子物理がどう機能するのかを、上辺をなぞるのではなく本当に説明すること。それは最初からこのプロジェクトの一部でした。そして私にとって、それは本当に楽しい仕事でした。
