# Colorpedia

[colorpedia.org](https://colorpedia.org) は、名前付きの色を集めた私のリファレンスです。そこでは色を英語とドイツ語の名前とともにカタログ化し、Hex コードと RGB 値を添えて、色のファミリーごとに整理しています。

作るにあたって、私にはいくつか大切にしたことがありました：

- 色はファミリーごとに探索でき、カード表示とグリッド表示を選べます。
- パレット全体をキーボードで操作でき、矢印キーで色をたどり、Enter で選択します。
- Hex コードや色名はワンクリックでコピーできます。
- お気に入りはブラウザにローカル保存されたままになります。
- インターフェースは英語とドイツ語の2言語で用意しています。

トラッキングは一切ありません。設定とお気に入りは Cookie とブラウザの localStorage の中で生きていて、このサイトにはそれ以上のものは必要ありません。
