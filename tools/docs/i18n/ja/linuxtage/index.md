# Linuxtage

ここには、コミュニティイベントでの私の講演とスライドを集めています。最初を飾るのはグラーツ・リナックスターゲ、グラーツ工科大学で毎年開催されるオープンソースカンファレンスで、このコレクションで最初の講演を私はそこで行いました。このイベントのプログラムアーカイブは2003年までさかのぼり、多くの年の録画が media.ccc.de などでネット上に無料で公開されています。

このコレクションは少しずつ育っていきます。各講演には、短い説明と関連資料を載せた専用のページを用意します。

## ケルンテン・リナックスターク

リナックスターゲには、いまではもう講演者としてだけ関わっているわけではありません。[Rene](https://www.computerei.at/) を中心とする Carinthian Linuxday 協会のチームとともに、私はリナックスターゲをケルンテンに持ってくる手伝いをしています。グラーツは、コミュニティカンファレンスが地域をどれだけ動かせるかを見せてくれました。まさにそれをケルンテンにも望んでいます。Netsnek はケルンテン・リナックスタークにスポンサーとして参加しています。

次回の日程はもう決まっています。[ケルンテン・リナックスターク2026](https://carinthianlinuxday.at/Veranstaltungen/CLD26/2026-10-30-cld.html) は2026年10月30日（金）の15時から、フィラッハの IT ギムナジウム St. Martin で開催され、入場は無料です。モットーの「21, is nua die hålbe Woarheit」は、この場所で最初の Linux イベントが開かれてからちょうど21年になることをかけたものです。キーノート、トーク、ワークショップ、そして Linux、オープンソース、デジタル主権をめぐるディスカッションが予定されており、飛び入りで何か見せたい人のためのライトニングトーク枠もあります。

10月まで待ちたくない人へ。毎月第2日曜の16時からは、Freiraum Myzel で [Linux-Stammtisch](https://carinthianlinuxday.at/Veranstaltungen/stammtisch.html) が開かれています。コーヒーと会話、そしてときどき小さなワークショップも。そこでは多くの Linux 好きに加えて、私や Netsnek チームの面々にも定期的に会えます。
