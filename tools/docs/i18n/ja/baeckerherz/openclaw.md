# OpenClaw シフト表ボット

[Bäckerherz](/docs/baeckerherz) では、ほとんどの人が起きる前に仕事の一日が始まっていました。誰がいつ焼き、ピッキングし、配達するかは、絶えず調整が必要でした。シフト表の調整は日々のオペレーション業務であり、私のパートナーである [Momo](https://www.linkedin.com/in/momo-matsumoto-746594290/) が担っていました。シフト表ボットはこの仕事を、チームがもともと書き込んでいた場所、つまり Telegram へ持っていきました。

## OpenClaw とは

OpenClaw は、パーソナル AI アシスタントのためのオープンソースのゲートウェイです。自前のハードウェア上でセルフホストされ、アシスタントを Telegram や WhatsApp といったメッセンジャーにつなぎます。専用ログイン付きの専用アプリの代わりに、チームはただメッセンジャーの中に、話しかけられる連絡先をひとつ持つだけです。

## 日常の中のボット

Bäckerherz では、この土台の上で Telegram のシフト表ボットが動いていました。チームは、別のアプリをインストールしたりどこかにログインしたりすることなく、チャットの中で直接シフト表を調整し、問い合わせることができました。日々の調整にとってそれは、紙が減り、聞き返しが減り、全員が携帯で見られる一枚の計画があるということでした。

## 運用とスタック

ゲートウェイは私のサーバーのひとつでセルフホストされていました。プロセスはローカルにのみバインドされ、外に向かって話すのはメッセンジャーへの接続だけでした。シフト表とチームのコミュニケーションはこうして、また別のサードパーティのもとではなく、自前のインフラの上にとどまりました。

## ボットの周りのツーリング

このボットは、同じパターンに従う一連の小さなツールの一部でした。シンプルで、日常に寄り添い、すぐに使える。

- 社内フローと情報管理の改善のためのデジタルフォーム。紙切れ仕事の代わりとして。
- Google My Maps 上の営業ルート。ツアーを見えるように、計画できるように。
- 経営判断の土台としての営業レポート。
- 分析のためにすべての注文を取得する Django バックエンドのコマンド。

どれも大きなものではありませんでした。どれも毎日使われました。まさにそれがアイデアでした。

## 私が持ち帰ったもの

このプロジェクトから得たパターン、つまりツールをチームがもともと働いている場所に持っていくというやり方を、私はいまでも使っています。
