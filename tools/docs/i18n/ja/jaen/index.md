# Jaen

このブログにあるほとんどすべてのプロジェクトが同じ土台の上に立っています。だからその物語も、ここに属します。Jaen は、[cronit](https://www.cronit.io) の [Nico](https://github.com/schettn) と一緒に開発している CMS です。私たちの掲げる目標は控えめではありません。コンテンツ管理を21世紀に連れてくることです。

従来の CMS で私たちがずっと気に入らなかったのは、その分断でした。こちらにウェブサイト、あちらに独自のフォームを持つ管理バックエンド、そしてその間には、決して完全な真実を語らないプレビュー。Jaen はそれをひっくり返します。CMS がウェブサイトそのものの中に住むのです。本物のサイト上でログインし、コンテンツがあるまさにその場所で直接編集します。目にしているものはプレビューではなく、そのページ自身です。

技術的には、Jaen は Gatsby のためのオープンソース CMS です。コンテンツは静的に一緒にビルドされるので、ページは高速なまま、サーバーなしでも配信できます。それでいて、すべてをブラウザーの中で編集できます。私たちが欲しかったのは、まさにこの組み合わせでした。静的サイトの堅牢さと、ページそのものであるエディターの即時性です。

Jaen は実際のプロジェクトの中で育ってきました。[PhotonQ](/docs/photonq) はそのリファレンスサイトの1つになり、netsnek.com は今度はその PhotonQ のコードから生まれ、あなたが今読んでいるこのテキストも Jaen が配信しています。最近、私たちは Jaen を多言語対応にしました。おかげでこのサイトはドイツ語、英語、スロベニア語、イタリア語、日本語で読めます。ただし私が書いているのはドイツ語版だけで、残りは機械翻訳です。

この土台には [Emailwerk](/docs/emailwerk) も属します。Nico との同じ協働から生まれたメールプロジェクトで、とりわけこのサイトのお問い合わせフォームを送信しています。

コードは公開されています: [github.com/jaenjs/jaen](https://github.com/jaenjs/jaen)。
