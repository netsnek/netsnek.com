# インターンシップ

このセクションには、私のところでインターンシップをした人たちと、彼らが取り組んだプロジェクトについての短い物語を集めています。名前や個人的な詳細は、本人が明示的に同意した場合にのみ掲載します。

## 2026年サマーインターンシップ：Mario

2026年6月、[Mario](https://taurok.com/) が Netsnek e.U. で1週間のサマーインターンシップを行いました。彼のメインプロジェクトは、Node.js と GraphQL をベースに自力で開発したリモート管理 API で、サーバーサービスをプログラムから管理し遠隔操作できるようにするものです。

そのかたわら、HTML、CSS、JavaScript を使った Web 開発にも参加し、Linux サーバー管理の実践経験を積みました。systemd でサービスをセットアップし、OpenSSL や RCON を扱い、自作の Bash スクリプトでデータバックアップを自動化しました。Mario は最小限の指示だけで自律的に作業を進め、一貫して非常に質の高い仕事を届けてくれました。

締めくくりには、詳細な評価付きの実習証明書を発行しました。自家製の LaTeX レポートテンプレートで組版し、ID Austria による適格電子署名で署名して、署名検証用の QR コードも添えました。

新しい物語は、それが生まれ、本人たちと内容をすり合わせられ次第、順次追加していきます。
