# Internships

This section collects short stories about people who did an internship with me, and about the projects they worked on. Names and personal details appear here only if the people involved explicitly agreed to it.

## Summer internship 2026: Mario

In June 2026, [Mario](https://taurok.com/) completed a one-week summer internship at Netsnek e.U. His main project was an independently developed remote management API based on Node.js and GraphQL, through which server services can be managed and controlled remotely in a programmatic way.

Alongside that, he contributed to web development with HTML, CSS and JavaScript and gained practical experience in Linux server administration. He set up services with systemd, worked with OpenSSL and RCON, and automated backups through a Bash script he wrote himself. Mario worked independently even with minimal instructions and delivered consistently very good work.

At the end there was a qualified reference letter, typeset on the in-house LaTeX report template and signed with a qualified electronic signature via ID Austria, including QR codes for verifying the signature.
