# Internships

This section collects short stories about people who did an internship at Netsnek e.U. and about the projects they worked on. Names and personal details appear here only when those involved have explicitly agreed.

## Summer internship 2026

In the summer of 2026, a student completed a one-week internship at Netsnek e.U. His main project was an independently developed remote management API based on Node.js and GraphQL, through which server services can be managed and controlled programmatically.

Alongside that, he contributed to web development with HTML, CSS and JavaScript and gained hands-on experience in Linux server administration. He set up services with systemd, worked with OpenSSL and RCON, and automated data backups with a Bash script he wrote himself. He already worked independently with minimal instructions and consistently delivered very good work.

At the end, he received a qualified reference letter, typeset on the in-house LaTeX report template and signed with a qualified electronic signature via ID Austria, complete with QR codes for verifying the signature.

More stories will follow as they happen and once they have been agreed with those involved.
