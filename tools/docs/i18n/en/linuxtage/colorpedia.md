# Colorpedia

[colorpedia.org](https://colorpedia.org) is an interactive reference for named colors, developed by Netsnek e.U. The site catalogs colors with their names in English and German, along with hex codes and RGB values, organized by color families.

## What the site can do

- Explore colors by family, in either card or grid view
- Keyboard control, moving through the palette with the arrow keys and selecting with Enter
- Copy a hex code or color name with a single click
- Save favorites, stored locally in the browser
- Bilingual interface in English and German

The site does without tracking. Settings and favorites stay in cookies and in the browser's localStorage.
