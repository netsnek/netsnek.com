# Prakse

Ta razdelek zbira kratke zgodbe o ljudeh, ki so pri meni opravljali prakso, in o projektih, pri katerih so delali. Imena in osebne podrobnosti se tu pojavijo samo, če so udeleženi izrecno privolili.

## Poletna praksa 2026: Mario

Junija 2026 je [Mario](https://taurok.com/) opravil enotedensko poletno prakso pri Netsnek e.U. Njegov glavni projekt je bil samostojno razvit API za oddaljeno upravljanje na osnovi Node.js in GraphQL, prek katerega je mogoče strežniške storitve programsko upravljati in daljinsko krmiliti.

Poleg tega je sodeloval pri spletnem razvoju s HTML, CSS in JavaScript ter nabiral prakso pri administraciji strežnikov z Linuxom. Postavil je storitve s systemd, delal z OpenSSL in RCON ter avtomatiziral varnostno kopiranje podatkov s samostojno napisano skripto Bash. Mario je pri tem delal samostojno že ob minimalnih navodilih in ves čas opravljal zelo dobro delo.

Ob zaključku je dobil kvalificirano delovno spričevalo, stavljeno na hišni predlogi LaTeX za poročila in podpisano s kvalificiranim elektronskim podpisom prek ID Austria, skupaj s kodami QR za preverjanje podpisa.

Nadaljnje zgodbe sledijo, takoj ko bodo nastale in usklajene z udeleženimi.
